# DMスクショ読み取りプロンプト（dm_screenshot_reader）

株式会社Colors代表（@zen_kaku）の X の DM 画面のスクリーンショットから、会話の内容を書き起こします。
分類や返信はしません。JSONのみを出力してください。

## 入力
- DM 画面のスクリーンショット（1枚以上。複数枚の場合は渡された順に上から下へ続く）

## 読み取りのルール
- **右側（自分側）の吹き出しは代表 = `me`、左側の吹き出しは相手 = `them`**
- 上から下へ、古い順に並べる。複数枚で重なっている部分は1回だけ書く
- 本文は見えている文字をそのまま書き起こす。要約・言い換え・補完をしない
- 途中で切れていて読めない吹き出しは含めない
- 日時、既読表示、「エンドツーエンドで暗号化されました」などのシステム表示、リンクのプレビューカードは本文に含めない
- `counterpart_name`：画面上部などに表示された相手の表示名。見えなければ null
- `counterpart_username`：相手の @ユーザー名（@ は付けない）。画面にはっきり見えるときだけ書き、推測しない。見えなければ null
- DM 画面と判断できない、または文字が読めない場合は `readable` を false にし、`messages` を空にする

## 出力形式（JSONのみ）
```json
{
  "readable": true,
  "counterpart_name": "山田太郎｜株式会社〇〇",
  "counterpart_username": "yamada_taro",
  "messages": [
    { "from": "me", "text": "フォローありがとうございます！…" },
    { "from": "them", "text": "経理の記帳をお願いできないかと思いまして…" }
  ]
}
```
